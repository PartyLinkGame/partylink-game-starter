# PartyLink developer kit

An optional starting point for a new PartyLink game: a playable sample, English AI prompts, and build/ZIP packaging scripts. Use it when you want to modify an existing example rather than start with an empty folder. To connect an existing game, use your own project with the integration prompt; the starter is optional.

Use prompts/create.md to create a game or prompts/integrate.md to adapt an existing game. Give your AI the selected English prompt; it links to the current official API reference. AI_CONTEXT.md is an optional offline snapshot. Localized guides are in docs/.

To try the starter, open starter/, run npm install, then npm run package. Import release/game.zip in PartyLink Library and scan the QR code with your phone. The starter installs @partylink/game-sdk@0.1.1 from npm.

Official developer documentation: https://doc.partylink.cc

Download [partylink-developer-kit.zip](https://github.com/PartyLinkGame/partylink-game-starter/raw/refs/heads/main/partylink-developer-kit.zip) from this repository, unzip it, then give the English prompt and the starter folder to your AI coding tool.
